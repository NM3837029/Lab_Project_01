# 東京ゲームショウ 出展カンペ

このフォルダは、ブースで **Editron** を説明するための紙です。
開発の手順書ではありません（それは [../README.md](../README.md) です）。

> **名前の使い分け**
> タイトル画面に出る作品名は **Editron**、副題は「2Dアクションゲームのためのゲームエンジン」です。
> `Lab Project 01` はリポジトリ・実行ファイルの名前なので、**お客さんには Editron と呼びます**。
> 同梱の7ステージは、その Editron（と付属エディタ Lab_Editor）で作ったゲームにあたります。

A4縦で印刷して、机に重ねて置いてください。立ったまま必要な紙を抜けるように、
1ファイル＝1〜3枚に収めてあります。

## 出展前のチェック

- [ ] `x64/Release/Lab_Project_01.exe` が最新のソースでビルドされている
- [ ] タイトル → ステージ選択を開き、**7本すべてが正しく開く**
- [ ] **セーブデータを消して初期状態にしてある**
      （Lab_Editor →「ゲーム設定」→「その他」→「セーブデータを削除」）。
      前の人の進行状況が残っていると、次の人が最初の面から始められません
- [ ] [05_数字と年表.md](05_数字と年表.md) の数字を、載っているコマンドで引き直した
- [ ] この6枚を印刷した（[01](01_30秒の掴み.md) は**裏に操作表**を刷る）

> ステージ選択のサムネイルは `img/thumb_*.png` です。
> ステージを作り直したら撮り直してください（ゲームをそのステージで起動して画面を撮るだけです）。
