# 30秒の掴み

**作品名は「Editron（エディトロン）」です。** タイトル画面にそう出ます。
`Lab Project 01` はリポジトリと実行ファイルの名前なので、お客さんには使いません。

## 最初の一言（これだけ覚える）

> **「時間と物体を“編集”して解く2Dアクションです。
> 敵は倒すんじゃなくて、向きを変えて道具として使います」**

言い切ってから相手の顔を見る。ここで止まってくれたら、下の分岐へ進む。

### 初手で言ってはいけないこと

**「時間を巻き戻せます」から始めない。** 巻き戻しは既にある作品が多く、
「ああ、あれね」で終わってしまう。このゲームの新しさは巻き戻しではなく、
**敵とギミックを倒す対象ではなく道具として扱う**ところにある。
巻き戻しは、そのための道具のひとつとして後から出す。

## 1分もらえたときに足す一言

- **「同じ操作でも、相手によって起きることが変わります」**
  トゲは45度倒すと刺さらなくなって足場になる。砲台は傾けると狙いが固定される。
  砲台を反転させると弾がプレイヤー側の弾になって、他の敵に当たるようになる。
- **「ステージごとに使える編集ツールを変えてあります」**
  道具を減らすほど解き方が一本道になるので、
  「何をすればいいか」ではなく「どう使うか」を考える形になる。
- **「作る道具のほうも自分たちで作りました」**
  ステージもアセットも敵の動きも、この隣にあるエディタで作っています。

## 操作表（この紙の裏に印刷する）

### 動かす

| キー | 動き |
|---|---|
| `A` / `D` | 左右に歩く |
| `W` | ジャンプ |
| `Enter`（または画面内を左クリック） | ショット |
| `Shift` | ダッシュ（ダッシュを取ったあと） |

### 編集する（このゲームの本体）

| キー・操作 | できること |
|---|---|
| `R` 長押し | 時間を巻き戻す |
| `Space` | 一時停止 ／ 再開（**止めた敵は足場になる**） |
| `Space` 中に `→` | コマ送り |
| `F` | 早送り（2倍） |
| `T` | 画面の色を変える（なし→赤→緑→青） |
| `Z` / `X` / `C` | ズーム ／ 暗くする ／ 明るくする |
| 右クリック | 敵やしかけを選んでメニューを出す |
| ドラッグ | 動かす |
| `S` + ドラッグ | 大きさを変える |
| `W` + ドラッグ | 高さを変える（しかけのみ） |
| `R` + ドラッグ | 回転させる |
| `Ctrl` + タイムライン帯を2回クリック | カット（区間を丸ごと飛ばす） |

### 覚えておく

- 編集には**ゲージ**を使う。使い続けると減り、放っておくと戻る。
  画面**左上の枠の下段**が残量（上段はコインの取得枚数）。残り2割を切ると赤く点滅する。
  **ドラッグでの変形だけは無料**。
- `Esc` でどの画面でもゲームが終了する。
- ステージ選択から戻るのは `BackSpace` か `X`。
- **矢印キー全押し**でゲームが閉じて Lab_Editor に戻る（開発用の隠し操作）。
