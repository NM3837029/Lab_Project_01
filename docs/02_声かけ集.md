# 声かけ集（自由に触ってもらうとき）

台本ではありません。**黙って遊んでもらうのが基本**で、この紙は
「詰まっているように見えたとき、何と言うか」の一覧です。

---

## 1. 座ってもらった直後の30秒

言うのは**3つだけ**。全部言うと覚えられません。

1. 「動かすのは **A と D**、ジャンプが **W** です」
2. 「止まりたくなったら **スペース**。時間が止まります」
3. 「敵やしかけは **右クリック** でいじれます」

巻き戻し（`R` 長押し）・拡大縮小（`S` + ドラッグ）・回転（`R` + ドラッグ）は、
**必要になった場面で初めて言う**。先に全部言うと手が止まります。

画面の左上に枠が出ていて、上段がコインの枚数、下段が**編集ゲージ**です。
編集を使うと減り、放っておくと戻ります。聞かれたらそう答えれば十分です。

---

## 2. 「詰まっている」の見分け方

| 様子 | どうするか |
|---|---|
| 同じジャンプを3回以上やり直している | **30秒待つ。** 続いたら声をかける |
| 手が止まって画面を見ている | **黙る。** ここで言うと一番もったいない |
| 右クリックを押して、閉じた | 「そのメニュー、下のほうも使えます」 |
| こちらを見た | すぐ答えてよい |

**答えを先に言わない。** このゲームは「思いつく」瞬間が面白さの中心なので、
そこを取り上げてしまうと何も残りません。段階的に、下の順で出します。

1. 「その敵、倒さなくていいです」 ← 方向だけ示す
2. 「止められます」「向きを変えられます」 ← 使う道具を示す
3. 実際の手順を言う ← 最後の手段

---

## 3. ステージ別・難所と答え

同梱は7本。ステージ選択に並んでいる順です。
**後ろの3本（かたむく丘・ほりぬきの坑道・わきあがる縦坑）は、
使える編集ツールをわざと絞ってあります。**
画面左の EDIT TOOLS 欄に、そのステージで何が使えるかが出ています。

### 前半4本（はじまりの草原 / 編集のとびら / たての塔 / いろの回廊）

編集ツールが**全部使える**面です。操作を覚えてもらう区間なので、
特に難所というものはありません。詰まったら
「使える道具が全部あるので、片っ端から試して大丈夫です」でよいです。

**「たての塔」は縦に登る面**（20×64マス）なので、
横スクロールだと思って右へ進もうとしている人には「この面は上へ登ります」と一言。

---

### かたむく丘（96×15・地上）

> 使える道具は **一時停止** と **オブジェクト編集** の2つだけ。

**時間が1本ぶんしかないならここを勧めてください。**
「敵を倒すのではなく働かせる」が4回続けて出てきます。

**① 入口の上段 — 罠**
コインが並んだ板の道は途中で切れていて、その先は棘の穴です。
→ 「そこ、行き止まりです。下の道が本線です」

**② 全高の壁の足元にある桃色のブロック**
弾でしか壊れません。ところが自分は弾を撃てません。
→ 「あの砲台、**反転させると味方になります**」
→ 右クリック →「向きを反転」。壁との間に立てば、追尾している弾がそのまま壁へ届きます。

**③ 横穴を塞ぐ土色の壁**
叩きつけでしか壊れず、しかも等倍では壊れません（1.3倍以上が必要）。
→ 「ドッスンを**横に倒して、大きくして**ぶつけます」
→ `R`+ドラッグで回す → `S`+ドラッグで拡大。
　 壁は左右どちらにもあるので、どちらへ回しても手応えが返ります（左の壁の中にコイン）。

**④ 谷 — 素では絶対に届かない**
→ 「追ってくる敵、**空中で止めると乗れます**」
→ 敵が谷の上に来たところで `Space`。

**⑤ 低い天井の通路にいる敵食らい**
通ろうとすると食われます。
→ 「巡回している敵を誘導すると、**相討ち**になります」

**⑥ 最後の青緑の壁**
体当たりでしか壊れません。
→ 「突進してくる敵の向きを変えて、ぶつけさせます」

### ほりぬきの坑道（110×20・地下）

> 使える道具は **巻き戻し** と **オブジェクト編集**。

落ちても取り返せる面なので、**「失敗しても戻せます」と先に言っておくと
大胆に遊んでくれます。**

**① 上層の行き止まり — 床が土色**
→ 「床、色が違うところがあります」
→ ドッスンを拡大して砕くと下層へ落ちられます。

**② 下層の広間 — 機械いもむしが斜めに跳ね回っている**
→ 「回して向きを変えるか、跳ね返りの周期を読んで抜けます」

**③ 上層へ戻る唯一の道 — 天井に埋まった桃色のブロック**
→ 「砲台を**真上へ回して**、反転させて撃ち抜きます」

**④ 重量スイッチ**
そのままでは軽くて反応しません。
→ 「箱を大きくして踏ませます」

**⑤ 近道に見えるちくわ床 — 罠**
乗ると抜け落ち、跳んでは出られない縦穴に閉じ込められます。
→ 「**巻き戻せます**（`R` 長押し）」。または底の箱を拡大して踏み台に。

---

### わきあがる縦坑（24×72・下から上）

> 使える道具は **一時停止** と **オブジェクト編集**。
> **巻き戻しが使えません。落ちたら下まで戻ります。** これは先に言ってください。

**① 登り全般**
3マスずつの棚で組んであるので、基本は素で登れます。

**② 1箇所だけ6マスの断絶**
ここだけは素で越えられません。
→ 「追ってくる敵を止めて、中継にします」

**③ 途中の部屋 — 真上向きに置いた機械いもむしが上下に跳ねている**
→ 「止めるか、回して逸らすかです」

**④ 縮小して置いてあるドッスン**
最初から乗れる台です（近道）。聞かれたら「それ、乗れます」。

**⑤ 棚の真上が棘になっている場所が2箇所**
**まっすぐ登ると死にます。** これは先に言ってよいです。

**⑥ 最後のゲート**
→ 「箱を大きくして重量スイッチに乗せます」

## 4. 壊せる地形の色の見分け方

壊せる地形は**画像を持たず色だけのブロック**にしてあるので、普通の地形と見分けがつきます。

| 色 | 壊し方 |
|---|---|
| **桃色** | 弾でしか壊れない → 砲台を反転させて味方撃ちにする |
| **土色** | 叩きつけ限定、しかも等倍では不可 → ドッスンを拡大してぶつける |
| **青緑** | 体当たり限定 → 突進してくる敵の向きを変えてぶつけさせる |

## 5. 相手が技術寄りだったときの差し込み

遊び終わったあと、隣の Lab_Editor を開いて見せます。**2つだけ。**

### (a) ブロックを差し替えて、その場で動きを変える

> アセット管理 → 敵を1体選ぶ → **「🧩 挙動スクリプトを編集」** →
> ブロックを2つ差し替える → OK → **「▶ プレイ」**

**C++ を再ビルドせずに敵の動きが変わる**ことが、これで一目で伝わります。
言う一言は「**ゲームの再ビルドはしていません**」。

### (b) 回転する棒ジェネレータ

> パーツ編集 → 左下の **「🌀 回転する棒として配置...」** → 個数と速さを入れる

マリオのファイアバーのような、一直線に並んだまま回る棒が一発で出ます。
中身は「全パーツが同じスクリプトを共有し、半径だけ自分の番号から決める」という形で、
**手でも組めるものをウィザードが自動生成しているだけ**。
しかも**生成したものを読み直して再編集できます**。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 進行不能・変なところに挟まった | `Esc` で終了して起動し直す |
| ゲームを閉じてエディタに戻したい | **矢印キー全押し**（開発用の隠し操作） |
| 前の人の進行状況が残っている | エディタ →「ゲーム設定」→「その他」→「セーブデータを削除」 |
| セーブの場所を聞かれた | `%LOCALAPPDATA%\LabProject01\save.json` |
| 「Windows によって PC が保護されました」 | 署名の無いソフト全てに出る。「詳細情報」→「実行」 |
| どっちの exe が動いているか分からない | エディタ画面下のステータスバーに出る |

> Lab_Editor が起動する exe は、`x64/Debug` と `x64/Release` のうち
> **後からビルドされた方**が自動的に選ばれます。
