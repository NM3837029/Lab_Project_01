# プレイ画面の右パネルの作り直し（設計）

日付：2026-11-26　対象：ゲーム本体（DrawPixel.cpp・EditPanel.h・ColorGrade.h）
見た目の案：Design キャンバス https://claude.ai/artifact/8vz5L7EyBDrQdW4PYCNQdm （2〜5枚目）

## 1. 目的と背景

テスターから、プレイ画面について次の声があった。

- インターフェイスをもっとスタイリッシュに。情報量が多すぎる
- 右パネルの上（選んだ物の編集）は、ボタンが小さく、何に対してできるのか分かりにくい
- 右パネルの下（色・明るさ）は、ごちゃごちゃしていて分かりにくい

実際のゲーム画面を撮って確かめた今の状態：

| 場所 | 今 | 困るところ |
|---|---|---|
| 右上（インスペクター） | 高さ22pxの行が7本（大きさ・角度・速さ・一時停止｜巻き戻し・動き・反応）。選んだ物は40pxの絵と名前1行 | 押せる所・ドラッグする所が見た目で分からない。名前が「…」で切れる。下の行が「その物」に効くことが伝わらない |
| 右下（カラー補正） | 前/後の帯、スライダー5本、色の輪、赤緑青×のボタン、数値3つ、注意書き2行（約20部品） | ゲームの判定とコストに効くのは「明るさ」と「色フィルタ」だけなのに、全部同じ重さ。「色相」が2か所（スライダーと色の輪の数値）で意味が違う。画面全体に効くことが書いていない |

## 2. ゴール／しないこと／失敗とみなすこと

**ゴール**
- 右パネルを色分けした2つの枠にし、「どこが何に効くか」を枠と色で伝える
  - 青い枠「選んだ物」：選んだ物のカード＋大きなタイル
  - オレンジの枠「画面全体」：色相の輪＋中の四角で、色フィルタと明るさを1か所で決める
- 押せる所・ドラッグする所が、見た目で分かる
- 常に見える部品の数を減らす（判定に効かない4項目はタブの奥へ）

**しないこと**
- 編集の中身（値の変わり方、コスト、判定のしきい値、取り消し）を変えること。変えるのは見た目と、パネルの上でのマウス操作の受け方だけ
- 右クリックの扇形メニュー、左のアイコンバー、モニターの中のHUD（コイン・HP・コストの枠、層のタブ、ヒント行）
- 下のタイムラインの帯（キャンバス4枚目では札を消していたが、今回は触らない）
- Lab_Editor 側の変更、ステージ・アセットのJSONの形の変更

**失敗とみなすこと**
- 同じ操作をしたのに、値・コスト・判定・取り消しの結果が今と変わる
- パネルの見た目と当たり判定がずれる（押した所と違う物が動く）
- 毎フレーム重い処理が増えて、60fpsを保てなくなる（例：毎フレーム `SetFontSize`、毎フレーム1画素ずつの描画）
- 封印されたステージで、触れないはずの操作が触れてしまう

## 3. 制約

- 画面は 1280×720 固定。右パネルは x=1030〜1280（幅250）、y=0〜620（下の100pxはタイムライン）。この大きさは変えない
- 描画は DxLib の図形・文字・画像だけ。文字は `UiFont`（サイズ別ハンドル）で描く。太字が要るなら `UiFont` に太さ違いのハンドルを足す（`SetFontSize` を毎フレーム呼ばない）
- 行の位置と当たり判定は、今と同じく「1つの表」で決め、描画・クリック・指差しカーソルの3か所が同じ表を見る（`Insp` 名前空間の `RowBox`/`RowAt` と `InspRowUsable`）
- 色フィルタ・明るさの判定は `ColorGrade::JudgeFilter` / `JudgeBright` のまま。値の範囲（明るさ 0.3〜1.7、強さ 0〜1、しきい値 0.6／1.3／強さ0.5／±35度）も同じ
- コメントは日本語で細かく書く（このリポジトリの約束）

## 5. 画面の作り

### 5.1 全体

- 右パネルの下地は今と同じ（暗い下地＋モニター側の青い縁3px）
- 中に角の丸い枠を2つ縦に置く
  - 青い枠「選んだ物」：x=1041〜1271, y=10〜286。縁は青（120,190,255）を半透明で
  - オレンジの枠「画面全体」：x=1041〜1271, y=296〜610。縁はオレンジ（242,166,90）を半透明で
- 2つの枠は、選んだ物が何であっても位置も高さも変わらない

### 5.2 青い枠「選んだ物」

**見出し**（1行）：青い点＋「選んだ物」、右端に小さく「右クリックで選ぶ」

**何も選んでいないとき**：カードとタイルの代わりに、点線の枠の中へマウスの絵（右ボタンが青い）と「画面の敵やギミックを右クリックで選ぶ」「選ぶと、ここにその物の大きさ・角度・速さなどのボタンが出ます」。押しても何も起きない。

**選んだ物のカード**（敵：高さ56、ギミック：高さ46）
- 青い縁2px。左に絵（今の `DrawThumb` と同じく枠に収める）
- 名前は、定義の名前を「（」の前と後ろで分け、前を太字で大きく、後ろを説明として小さく出す（例：「回転させる敵」＋「近くの物を回し続ける」）。括弧が無い名前は1行
- 右上に小さな札：敵は「敵 HP3」、ギミックは「ギミック」、プレイヤーは「自分」
- 複数選んだときは「3個まとめて」、カット区間は「カット区間」（今の名前の決め方のまま）

**タイル**（3列。敵・プレイヤーは2段×高さ62、ギミックは3段×高さ48。間隔6）

| 段 | 敵 | プレイヤー | ギミック |
|---|---|---|---|
| 1 | 大きさ／角度／速さ | 大きさ／角度／速さ | 大きさ／角度／速さ |
| 2 | 一時停止／巻き戻し／動き | 一時停止／巻き戻し／（空き） | 一時停止／巻き戻し／上下反転 |
| 3 | — | — | 色相／明るさ／透明度 |

- **値のタイル**（大きさ・角度・速さ）：左上に小さなアイコン＋項目名、中央に値を大きく、下に細い帯（いまの値の位置）。左右ドラッグで値が変わる（今の行と同じ計算）。マウスが乗っている間は帯の代わりに「◀ ドラッグ ▶」を出す。つかんでいる間は青く光る
- **切り替えのタイル**（一時停止・巻き戻し・上下反転）：アイコン＋名前＋「ON/OFF」。ON のときは青い下地
- **巡回のタイル**（動き・色相・明るさ・透明度）：クリックで1段ずつ進む（今と同じ）。動きは今の動きの名前を緑で
- 初期値から変えた値のタイルには、右上に青い点
- そのステージで禁止されている操作・その対象では意味の無い操作のタイルは、沈んだ色にして小さな錠前を付ける（`InspRowUsable` が false の物）
- 物の編集そのものが封印されたステージでは、青い枠全体を沈めて「このステージでは物の編集が封印されています」

**効いている編集**（タイルの下、1行）：「効いている編集」＋チップ（拡大・加速…今と同じ並べ方）。何も無いときは行ごと出さない。入りきらない分は「…」

**モニター上の選択枠**：選んだ物を囲む今の黄色い枠を、パネルと同じ青の「角かっこ」（四隅だけの線）に変える。どんな背景でも見えるよう、青い線の外側に1pxの暗い縁を付ける。ギミックの大きさのつまみ（黄色い四角）は今のまま。

### 5.3 オレンジの枠「画面全体」

上から順に：

1. **見出し**：オレンジの点＋「画面全体」、右端に「リセット」（全部を初期値へ。今の全リセットと同じ）
2. **タブ2つ**：「色と明るさ［コスト］」｜「細かい調整［無料］」。選んでいるタブだけ明るい下地。どちらのタブを開いているかはパネルの状態として持ち、ステージを出入りしたら「色と明るさ」に戻す
3. **「色と明るさ」タブの中身**（高さ約192）
   - **外の輪（色相）**：外径 半径91／内径 半径77 の色相の輪。向きは今の色の輪と同じ（右＝赤0度、左上＝緑120度、左下＝青240度）。輪の上の小さなつまみが今の `tintHue`
   - **判定の弧**：輪のすぐ外に、赤・緑・青それぞれ ±35度 の範囲を太さ4pxの弧で描く。輪の外側の8pxの帯と、四隅の文字「赤」「緑」「青」をクリックすると、その色にぴったり合う（`SetQuickFilter` と同じ：色相＝中心、強さ＝1）
   - **中の四角**（104×104、輪の中心に置く）
     - 横＝フィルタの強さ `tintAmount`（左端0〜右端1）
     - 縦＝明るさ `bright`（下端0.3〜上端1.7、真ん中が1.0）
     - 塗りは「その点を選んだら画面に掛かる色」：`TintMultiplier`（色温度は除く）×明るさ。明るさが1を超える上半分は、白へ寄せて薄くした色で表す（白より明るい色は描けないため）
     - 判定の境目を点線で描く：横線2本（明るさ0.6と1.3）、縦線1本（強さ0.5）。左上に小さく「明るい」、左下に「暗い」
     - 今の値の位置に白い丸のつまみ
   - **右下の2色**：手前の大きいほう＝いま画面に掛かっている色（色温度も含めた乗算の色）、後ろの白＝元の色。白を押すと、明るさと色フィルタだけ初期値へ戻す
   - **四隅の文字**：左上「緑」、右上「赤」、左下「青」（クリックで合わせられる）
4. **判定のチップ**（1行）：「明るさ：暗い／ふつう／明るい」「フィルタ：なし／赤／緑／青」。暗い＝青系、明るい＝黄系、赤緑青はそれぞれの色の札
5. **キーのヒント**（小さく1行）：「X / C で明るさ　T で色　点線＝判定の境目」

**「細かい調整」タブの中身**：コントラスト・彩度・色相・色温度のスライダー4本（今のスライダーと同じ値・同じ色の溝・ダブルクリックで初期値）。輪と四角があった場所に入れ替わりで出す。

**「このステージで使う」の札**：今のステージに、コントラスト・彩度・色相・色温度を見る補正スイッチ／補正ロック足場（ギミック26・27で、見る値が1〜4。置いた物ごとの上書きも含む）があるときだけ、「細かい調整」のタブに小さなオレンジの札を付ける。タブを自動で切り替えはしない。

**封印**：画面エフェクトが封印されたステージでは、オレンジの枠全体を沈めて「このステージでは画面エフェクトが封印されています」（今と同じ考え方）。

**消す物**：前/後の帯、5本並びのスライダー（4本はタブの奥へ、明るさは四角の縦へ）、今の小さな色の輪、赤緑青×のボタン、色相・強さの数値、注意書き2行。

### 5.4 マウス操作（画面全体の枠）

| 操作 | 結果 |
|---|---|
| 輪を押す／ドラッグ | 色相 `tintHue` が変わる（強さはそのまま。強さ0なら、輪を押した時点で強さを1にする） |
| 四角を押す／ドラッグ | 強さ `tintAmount` と明るさ `bright` が同時に変わる。真ん中（明るさ1.0）と左端（強さ0）の近くでは吸い付く |
| 判定の弧・四隅の文字を押す | その色にぴったり合わせる |
| 四角をダブルクリック | 明るさと強さを初期値へ |
| 輪をダブルクリック | 強さを0へ（今の色の輪と同じ） |
| ホイール（四角の上） | 明るさを ±0.05 |
| ホイール（輪の上） | 色相を ±5度 |
| 白い四角（元の色）を押す | 明るさと強さを初期値へ |
| タブを押す | タブを切り替える |

- つかんでいる間は今と同じく世界を止め（`isColorDrag`）、枠の外へ出てもつかんだまま
- 枠の上のクリック・ホイールは、背後の編集操作へ回さない（今と同じ）
- X / C を押している間（明るさを一時的に0.3／1.7にする今の操作）は、四角のつまみをその高さに薄く重ねて描く
- 枠の上にマウスがある間、ヒント行に「ダブルクリックで元に戻す」を出す

## 6. 作り方の指針

- **右パネル上半分**：`Insp` 名前空間の表を、行（y座標）からタイルの矩形へ書き換える。`RowBox`/`RowAt`/`InspRowUsable` の使い方は今のまま残し、クリック処理（`DrawPixel.cpp` のインスペクターのドラッグと切り替え）と指差しカーソルの処理は、表が変わるだけで動くようにする。タイル・カード・空の状態の描画部品は `EditPanel.h` に足す
- **右パネル下半分**：`ColorGrade.h` の「4. パネル」の配置定数・`Update`・`Draw` を作り直す。値（`PanelState`）・判定・画面への掛け方（1〜3章）は変えない。タブの状態は `PanelUi` に足す
- **色の輪と四角の絵**：輪は今の色の輪と同じく起動時に1回だけ画像を作る。四角は画像を作らず、頂点ごとに色を付けた四角形（DxLib の `DrawPrimitive2D` など）を3枚重ねて毎フレーム描く。四角の色はどれも位置について一次式なので、頂点の色で正確に出せる
  - 1枚目：左の2頂点＝白、右の2頂点＝その色相で強さ1のときの乗算の色（`TintMultiplier`）
  - 2枚目（下半分）：黒を、真ん中で透明・下端で不透明度0.7（＝明るさ1.0→0.3）
  - 3枚目（上半分）：白を、真ん中で透明・上端で半透明（明るさ1.0→1.7 を「白っぽく」見せる）
  - 輪をドラッグして色相が毎フレーム変わっても、画像の作り直しは起きない
- **選択の並び**：敵・プレイヤーの2段か、ギミックの3段かは、今の `Insp::lookMode` の決め方（`SyncInspMode`）に従う。いろいろな種類をまとめて選んだときも今と同じ
- **「このステージで使う」の判定**：ステージを読み込んだときに1回だけ調べて覚えておく
- **角の丸い枠**：`DrawRoundRectAA` などで描く。描けない環境のことは考えなくてよい（DxLib の D3D11 で動いている）

## 7. 確かめ方

- 今までの検証と同じく、ユーザーのソースや assets を触らない別ビルド（scratchpad にソースをコピーし、偽のマウス入力と画面保存のフックを入れる）で、次の画面を撮って見比べる
  - 何も選んでいない／敵／ギミック／プレイヤー／複数選択／カット区間
  - 物の編集の封印・操作ごとの禁止・画面エフェクトの封印
  - 色と明るさタブ（ふつう・赤・暗い＋青・明るい）、細かい調整タブ、「このステージで使う」の札
- タイルのドラッグ・クリック、輪・四角・弧・白い四角のクリックとドラッグを偽の入力で行い、値・判定（`JudgeFilter`/`JudgeBright`）・コストの減り方が今と同じであることをログで確かめる
- 1秒60コマを保てていること（今までの計測と同じやり方）

## 8. 作る人に任せること

- 文字の大きさ（11〜16pxの範囲で）、アイコンの細かい形、色の細かい値
- 値のタイルの帯の範囲（既存の上限・下限に合わせる。上限の無い速さは0〜3倍で表示し、超えたら満タン）
- 吸い付く範囲の幅、ダブルクリックの間隔（今と同じ20フレームが目安）
