# 2000年代の編集ソフト風テーマ（案A既定・案Bを設定で切替）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** プレイ画面のまわり・扇形メニュー・Esc メニューを「2000年代の編集ソフト風」の2つの見た目（暗い灰色＝既定／明るい灰色）で描き、Esc メニューの「設定」で切り替えてセーブに残す。

**Architecture:** 新しい `UiTheme.h` に色の表（2種類）と共通の描き方（盛り上がり・へこみ・タブ・見出しバー・目盛り・状態バー・選択の点線）を置き、各部品の描画をそれに置き換える。配置・当たり判定・操作は変えない。切替はセーブデータの `ui_theme` に残す。

**Tech Stack:** C++17 / DxLib / MSBuild（VS2022 v143）

**Spec:** `docs/superpowers/specs/2026-11-26-ui-theme-2000s-design.md`

## Global Constraints

- 画面 1280×720。左バー x=0〜68、右パネル x=1030〜1280、下のパネル y=620〜720。配置・当たり判定は変えない（`Insp::RowBox`・`ColorGrade::HitPart`・`EditToolbar::ButtonRect`・カットの帯 y=660〜680／当たり y=660〜700・`RadialSectorAt`）
- 色は `UiTheme` の表から取る。部品のコードに `GetColor(数値)` を直接書かない（ゲームの中の物の色は除く）
- 文字は UiFont 経由。書体は「MS UI Gothic」・ぼかしなし（`DX_FONTTYPE_NORMAL`）、無ければメイリオ・アンチエイリアス。毎フレーム `SetFontSize` を呼ばない
- 角丸・半透明の縁は使わない（`DrawRoundRectAA` と縁の `DX_BLENDMODE_ALPHA` を、テーマの部品から無くす）
- セーブは `%LOCALAPPDATA%\LabProject01\save.json`。キー `"ui_theme"`：`"dark"`（既定）／`"light"`。無い・読めない値は dark
- 自作ソースは BOM 付き UTF-8・CRLF。コメントは日本語で細かく。`std::min/max` は `(std::min)(...)` の形で
- ユーザーの `assets/` の作業中ファイル（`Color.json`・`mumei.json`）に触れない。push はしない
- 検証の実行では、環境変数 `LOCALAPPDATA` を scratchpad のフォルダに向ける（ユーザーの本物のセーブに書かない）

1. 明るい灰色で、白い文字や薄い青の文字が地に溶けて読めなくなる所（HUD の札・トースト・カード・扇形メニュー）→ Task 1 の `contrast_*` テストで表の組み合わせを固定し、Task 9 の撮影で全画面を両テーマ確認
